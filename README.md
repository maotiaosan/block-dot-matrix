# 画布点阵 (block-dot-matrix)

给 Block 笔记铺一层和正文行高对齐的点阵或方格背景，帮助弱视读者稳定地一行一行往下读。设置方式与 Thinkly 的「画布 → 编辑器网格」一致。

## 设置

- **编辑器网格**：无 / 方格 / 点阵
- **网格深浅**：标准（Thinkly 默认浓度）/ 加深（点更大、更深，适合弱视）

点击「打开点阵阅读页」，会把当前笔记生成一份带点阵背景的阅读页，保存到下载目录并直接打开。点阵四周留出对称的空白，不会贴边或被裁成半个点。

## 安装

在 Block 中打开「设置 → 应用商店」，搜索 **画布点阵** 安装；或在「手动安装」中输入：

```text
maotiaosan/block-dot-matrix
```
