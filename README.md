# 点阵阅读 (block-dot-matrix)

面向视障与弱视用户的 Block 无障碍可读性插件：将 Markdown 笔记转换为 **Unicode Braille 盲文点阵**、**高对比度防串行点阵大字阅读页（HTML）**，以及**可打印 A4 触觉盲文点阵图（SVG）**。

## 核心能力

- **Unicode Braille 盲文点阵转换**：支持英文 Grade-1 6 点盲文、数字/大写引导符、Markdown 标题/引用/列表结构标记，以及中文汉字的盲文点阵分组编码。
- **高对比度点阵大字阅读页（单文件离线 HTML）**：
  - 提供三套 WCAG AAA 高对比度配色（暗夜金黄、纯黑亮白、深海暖白）；
  - 可调防串行定位点阵网格与左侧行号锚点，降低弱视阅读跳行与视觉疲劳；
  - 支持点击锁定焦点行、动态调字号、盲文双轨对照、读屏器 ARIA 语义跳转与浏览器语音朗读。
- **可打印 A4 触觉点阵图（SVG）**：输出带实心凸点与空心基准点位的矢量 SVG，可用于触觉压凸打印或配合放大镜阅读。
- **笔记内嵌盲文块与保存自动同步**：可幂等写回当前笔记末尾的 `<!-- block-dot-matrix:start -->` 区块，并支持开启「保存笔记后自动同步盲文块」。

## 安装方式

在 Block 中打开「设置 → 应用商店」，搜索 **点阵阅读** 安装；或在「手动安装」中输入：

```text
maotiaosan/block-dot-matrix
```
