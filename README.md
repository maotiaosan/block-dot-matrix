# 画布点阵 (block-dot-matrix)

复刻 Thinkly 的 **画布 → 编辑器网格（无 / 方格 / 点阵）** 体验，为 Block 笔记提供与正文字号和行高对齐的点阵/方格画布背景，并加入多档对比度与行焦点防串行引导，帮助弱视及视障用户更轻松地追踪阅读行。

## 核心功能

- **Thinkly 同款三档编辑器网格**：支持 **无（Off）**、**方格（Grid）**、**点阵（Dots）** 实时切换，网格步距按 `font-size × line-height` 自动对齐文字行高。
- **视障与弱视可读性增强**：
  - 三档点阵对比度：柔和（Thinkly 默认 `0.07 / 0.16`）、清晰增强、视障高对比；
  - 三套纸面主题：浅色纸面、暖色护眼、暗夜高对比；
  - 支持行焦点防串行高亮、弱视大字增强（`+4px`）与实时字号缩放。
- **离线点阵画布阅读页 & A4 点阵纸导出**：
  - 一键打开带真实方格/点阵底纹的离线 HTML 阅读画布；
  - 支持导出可打印 A4 点阵/方格纸（SVG）与 `canvas-modes.css` 样式变量。

## 安装方式

在 Block 中打开「设置 → 应用商店」，搜索 **画布点阵** 安装；或在「手动安装」中输入：

```text
maotiaosan/block-dot-matrix
```
